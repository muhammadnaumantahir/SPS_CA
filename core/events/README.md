# Event Contracts

Cross-layer events provide the traceable communication mechanism. Initial event vocabulary includes `TaskCreated`, `PlanCreated`, `CapabilitySelected`, `CodeGenerated`, `FileModified`, `TestStarted`, `TestFailed`, `AdaptationRequested`, `CapabilityCandidateCreated`, `GovernanceDecision`, `ValidationCompleted`, `CapabilityRegistered`, and `RollbackExecuted`.

Implement typed event contracts in Phase 1; do not let the UI become the event store.
