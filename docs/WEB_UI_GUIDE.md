# SPS-CA Web UI Guide

The UI presents the same architecture used by the runtime. It reads layer names and sub-components from `layers.architecture` so the UI cannot drift from the authoritative architecture.

For each layer the control-center view can show its canonical name, purpose, implemented sub-components, runtime status, and trace activity. The Brain is shown separately as the reasoning service.

## Canonical layers

- L1 Software DNA Core
- L2 Governance Core
- L3 Cognitive core
- L4 Knowledge core
- L5 Experience core
- L6 Meta-learning core
- L7 Adaptation core
- L8 Evolution core
- L9 Verification & Validation Core
- L10 Execution Core

Layer 8 should expose the SPS Growth Decision and its evidence-backed outcome. A disagreement event alone must never be presented as automatic capability creation.
