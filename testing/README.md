# SPS-CA Testing

Testing is separated from production implementation.

- `unit/` — cross-layer unit tests
- `integration/` — subsystem integration tests
- `system/` — end-to-end SPS workflows
- `scenarios/` — reproducible research scenarios
- `baselines/` — baseline agent comparisons
- `benchmarks/` — repeatable benchmark workloads
- `evaluation/` — thesis evaluation and metric collection

Layer-specific tests remain beside their layer under `layers/`.
