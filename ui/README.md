# SPS-CA UI

The UI is a presentation/control layer only.

Planned areas:

- `frontend/` — dashboard and project/session views
- `backend/` — UI-facing application services/API
- `visualization/` — graph-ready view models and visualization adapters
- `components/` — reusable UI components

Planned visualizations include capability lineage/genealogy, capability growth over time, task/experience/evolution relationships, model performance, validation results, and execution traces.
